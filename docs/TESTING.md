## 车机人工回归

记录 APK 版本 / SHA256、Android 版本、分辨率、density、导航模式、播放器名称 / 版本和音乐来源。

| 场景 | 观察 / 通过依据 |
| --- | --- |
| 冷启动，不进入本应用，直接播放 | 服务 / 音频历史完整，律动能恢复；记录延迟，不只拍最后成功状态 |
| 熄火后短时 / 长时休眠再唤醒 | 通过 boot count 和两种时钟区分休眠 / 重启，观察恢复 |
| 暂停再播放，多次重复 | 没有长期无回调，或失败时有重试和异常记录 |
| 切换播放器 | 会话判断与真实频谱均合理 |
| 普通页面 ↔ 沉浸式全屏 | 导航栏显示时避让，隐藏稳定后贴底，来回切换无累计边距 |
| 底部 / 侧面导航栏、旋转 | 屏幕实际底边映射正确，不出现仅上边可见 |
| 键盘弹出 / 收起 | 不把整块键盘高度误当成导航栏 |
| 自动底边开 / 关 | 自动值不叠加旧手动值，关闭后恢复原手动设置 |
| 系统媒体音量为 0 但车机实际可听 | 兼容判断可继续检查播放，仍以真实 FFT 为准 |
| 录音 / 悬浮 / 通知权限撤销再授予 | 无崩溃，状态与原因可诊断，恢复行为有记录 |
| 关闭悬浮功能 | 尊重禁用状态，不被看门检查强行拉起 |
| 重复导出、重启后导出 | Download 路径和文件名正确，单文件 ≤ 2 MiB，旧记录可追溯 |

问题重现后进入本应用再导出会改变当前状态，必须结合此前历史分析。
