# 153：移除桌面快捷入口与 152 日志复核

## 修改范围

用户要求移除安装后车机桌面出现的“息屏显示”和“设置”入口。原 APK 只有一个 MAIN + LAUNCHER Activity，即 `HomeActivity`；没有另外两个 launcher Activity 或 activity-alias。

两个入口定义在 `decoded/res/xml/shortcuts.xml`，ID 分别为 `settings_shortcut` 和 `aod_shortcut`，通过 `HomeActivity` 下的 `android.app.shortcuts` 元数据向桌面发布。这是 Android 静态快捷方式，手机桌面一般显示在长按菜单，车机桌面可以将它们呈现为独立入口。完整 smali 和辅助层未找到动态发布 / 固定快捷方式的 API 调用。

153 只删除 `decoded/AndroidManifest.xml` 中这一条元数据注册，停止向系统发布两个快捷方式。保留原 XML、图标和字符串资源，以维持资源 ID 和二进制资源一致性；保留唯一主图标、应用内设置和息屏功能。此变更对手机和车机都生效，手机长按菜单中的这两个快捷方式也会消失。音频、导航栏自适应、授权、服务和原始 smali 均不改动。Java 中只更新两处诊断版本文字。

因此移除这种入口只需要修改 XML 配置，无需修改 Java / smali 的业务逻辑。但 APK 里的 Manifest 是编译后的二进制 XML；应反编译、修改、重新构建并签名，不能把普通文本 XML 直接塞回 APK 后继续沿用原签名。本仓库正式证书与 152 相同，可以覆盖安装。若桌面保留已经固定或缓存的旧快捷图标，应用不能保证替桌面清除：先返回桌面或重启车机；仍残留时只移除旧快捷图标，保留主应用及数据。
